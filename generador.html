Generador de entradas

Importa desde TMDB o rellena manual → genera el código para Blogger

1 Configuración

Tu API key de TMDB (gratis en themoviedb.org → Ajustes → API). Se guarda solo en tu navegador.

Se crearán estas pestañas de idioma en cada episodio para que pegues los servidores.

2 Importar desde TMDB (opcional)

Busca la serie o película; al elegirla rellenamos todo (título, póster, sinopsis, géneros, reparto y episodios).

3 Datos de la entrada

Edita lo que quieras. Puedes empezar vacío (manual) o tras importar de TMDB.

4 Episodios

Rellena los servidores por idioma (Nombre + URL). YouTube, Drive, Vimeo, OK.ru y .mp4/.m3u8 se reproducen solos.

5 Código para la entrada de Blogger

Pega esto en el cuerpo del post (vista HTML). Pon el título en el campo de título de Blogger, y las etiquetas/géneros en las labels.
